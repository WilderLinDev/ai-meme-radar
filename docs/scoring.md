# 评分

满分 100。五个分项各 0–20：热度 `heat`、趋势 `trend`、分享率 `share`、竞争 `competition`、窗口 `window`。Agent 只写五项分和理由，总分由代码求和。缺数据时保守给分，不插值，不编造。

`radar scaffold` 会在每个梗的 `facts.hints` 里按下面的档位给出热度、趋势、分享率的参考档；最终分数仍由 Agent 定。

数字标注：【已核实】、【第三方读数】、【估算】。

## 热度

看当前绝对体量，不看情绪。

- ViralRemix 日新视频 ≥40K，或 X 7 日发帖 ≥10 万，或原片/话题 7 日播放极高 → 18–20
- VR 20–40K，或二创中位播放千万级 → 16–17
- VR 5–20K，或 CC 7 日播放两千万级 → 12–15
- VR 1–5K、Turnly 创作者 50+，或原片约百万 → 8–11
- 早期信号或日产量几百 → 4–7
- 几乎没有当前产量 → 0–3

X 讨论热、但不是视频梗的，仍按讨论体量给热度分，再在竞争和窗口里压下去。

## 趋势

看曲线方向，以及是否仍在高峰。趋势和窗口都由生命周期驱动。

- 明显上升，或刚攻上日榜 → 16–20
- 接近峰值（低于最高点约 15% 以内且仍高位） → 12–15
- 处在峰值或走平 → 8–11
- 回落 15–40% → 4–7
- 回落超过 40%，或已离开 Creative Center 7 日榜 → 0–3

没有可用曲线时给 8，不假设它在涨。尾部的 0 如果是缺口，按缺口处理，不当作真实归零，除非页面确实给出 0。

## 分享率

用已排除原视频的高播二创中位分享率（分享/播放）。

- ≥3% → 18–20
- 2–3% → 15–17
- 1–2% → 12–14
- 0.6–1% → 8–11
- 0.3–0.6% → 4–7

n<5 记样本不足，这一项给保守分 6，不编造。TikTok 分享和 X 转发分开看。

## 竞争

模板和一键站越少，分越高。

- 没有核实到 CapCut 主模板，站外也没做开 → 18–20
- 有模板，但用量远低于音频/话题体量（缺口大） → 14–17
- 已有若干站点或中等用量模板 → 10–13
- 多站和模板都在做 → 6–9
- CapCut 已经铺开，或根本不是可产品化的视频格式 → 2–5
- 涉及未授权 IP/肖像，不能做成产品 → 0–1

## 窗口

还剩多少天值得投入。

- 季节性长窗口（如圣诞还有数周），或 ≥7 天 → 18–20
- 约 5–7 天 → 14–17
- 约 3–5 天 → 10–13
- 2–3 天，或先观察 48 小时 → 6–9
- 只适合文案变体，或维持已有能力 → 3–5
- 窗口已关闭，或不应做 → 0–2

## 裁决

代码先按分数给出建议结论（`suggested_verdict`）：

- 做 `make`：总分 ≥65 且窗口项 ≥10。
- 观望 `watch`：总分 45–64，或总分 ≥65 但窗口项 <10。
- 不做 `skip`：总分 <45。

Agent 的结论可以和建议不同（否决），但必须填 `override_reason`，日报会写出「按分数应为 X，否决：…」。常见否决：

- 基数很小的早期信号，分数不到 45 仍判观望。
- 在回落但仍有分享率，判观望。
- 分数不低，但本质是手绘同人、未授权 IP、CapCut 已做开、不是 AI 视频梗、季节彻底结束，判不做。

## 生命周期（代码计算）

- 已火天数 = 报告日 − 起火日期（`ignite_date`，Agent 填）。同一天起火记 0 天。
- 高峰状态只看主热度口径的完整点：最后一点就是峰值且高于前一点为「上升中」，等于前一点为「峰值」；低于峰值 15% 以内为「接近峰值」，否则为「回落 x%」；少于 2 个点为「数据不足」。
- Creative Center 曲线读数为 0 的日期按缺口处理。未满日（`complete=false`）可以画，不参与计算。

## D+3 回测

`radar build` 每天对追踪表里所有结论重跑一次。D+3 按自然日算，周五的推荐在下周一复核。

- 基线：推荐日 D 当天或之前最后一个完整主热度点。
- 做：D+3 完整点严格高于基线记为对（hit），否则错（miss）。同一个梗连续多个报告日都判做，只有首日计入命中率。
- 观望 / 不做：D+3 比基线高 20% 及以上记为漏判（miss），否则未漏判（hit）。漏判率 = 漏判 ÷（漏判 + 未漏判）。
- 待定（pending）：D+3 还没到。数据不足（insufficient）：主热度口径为 `none`、没有基线、或没有 D+3 完整点。
- X 发帖和 ViralRemix 是绝对数，取任意一天抓到的最新完整读数。Creative Center 指数每次抓取都重新归一化到 0–100，所以基线和 D+3 必须取自同一次抓取，不能跨抓取比较。
- 主热度口径以推荐日追踪表里记下的为准；之后改名册不影响已有推荐的回测。

如果命中率差或漏判率高，在当天 `notes` 里写明是哪一项分数误导了判断，以及今天怎么调整。
