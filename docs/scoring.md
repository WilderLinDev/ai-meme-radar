# 评分

满分 100。五个分项各 0–20：热度、趋势、分享率、竞争、窗口。总分必须等于五项之和。缺数据时保守给分，不插值，不编造。

数字标注：【已核实】、【第三方读数】、【估算】。

## 热度

看当前绝对体量，不看情绪。

- ViralRemix 日新视频 ≥40K，或 X 7 日发帖 ≥10 万，或原片/话题 7 日播放极高 → 18–20
- VR 20–40K，或二创中位播放千万级 → 16–17
- VR 5–20K，或 CC 7 日播放两千万级 → 12–15
- VR 1–5K、Turnly 创作者 50+，或原片约百万 → 8–11
- 早期信号或日产量几百 → 4–7
- 几乎没有当前产量 → 0–3

X 讨论热、但不是视频梗的，仍按讨论体量给热度分，再在竞争和窗口里压下去。

## 趋势

看曲线方向，以及是否仍在高峰。趋势和窗口都由生命周期驱动。

- 明显上升，或刚攻上日榜 → 16–20
- 接近峰值（低于最高点约 15% 以内且仍高位） → 12–15
- 处在峰值或走平 → 8–11
- 回落 15–40% → 4–7
- 回落超过 40%，或已离开 Creative Center 7 日榜 → 0–3

没有可用曲线时给 8，不假设它在涨。尾部的 0 如果是缺口，按缺口处理，不当作真实归零，除非页面确实给出 0。

## 分享率

用已排除原视频的高播二创中位分享率（分享/播放）。

- ≥3% → 18–20
- 2–3% → 15–17
- 1–2% → 12–14
- 0.6–1% → 8–11
- 0.3–0.6% → 4–7

n<5 记样本不足，这一项给保守分 6，不编造。TikTok 分享和 X 转发分开看。

## 竞争

模板和一键站越少，分越高。

- 没有核实到 CapCut 主模板，站外也没做开 → 18–20
- 有模板，但用量远低于音频/话题体量（缺口大） → 14–17
- 已有若干站点或中等用量模板 → 10–13
- 多站和模板都在做 → 6–9
- CapCut 已经铺开，或根本不是可产品化的视频格式 → 2–5
- 涉及未授权 IP/肖像，不能做成产品 → 0–1

## 窗口

还剩多少天值得投入。

- 季节性长窗口（如圣诞还有数周），或 ≥7 天 → 18–20
- 约 5–7 天 → 14–17
- 约 3–5 天 → 10–13
- 2–3 天，或先观察 48 小时 → 6–9
- 只适合文案变体，或维持已有能力 → 3–5
- 窗口已关闭，或不应做 → 0–2

## 裁决

- 做：总分大约 ≥65，窗口项 ≥10，而且不是版权或错误格式问题，趋势也不是大幅回落。
- 观望：大约 45–64 分，或基数很小的早期信号，或在回落但仍有分享率。
- 不做：低于约 45 分，或 CapCut 已做开、不是 AI 视频梗、未授权 IP、季节彻底结束。

质量判断可以否决分数。例如分数不低，但本质是手绘同人，仍然不做。

## D+3 回测

某天推荐「做」的梗，若 D+3 当天有完整主热度，且严格高于推荐日行里记下的基线，记为对。有完整点但不高于基线，记为错。没有日序列、基线或 D+3 完整点，记为数据不足。不插值。脚本是 `scripts/backtest.py`。
